## Not verified

- Exact installed device variant and Rig Manager / Profiler OS versions.
- Exact Sinewave Continuum OD file names, gains and the free Tone Junkie profile settings.
- Availability/behavior of all named factory preset labels in the user's software.
- Exact effects order in all artists' recordings, which often changed live/studio.
- Whether physical guitar pickups and circuitry can match reference recording (e.g., Clapton SG woman tone; Mayer Casino/P-90 outro fuzz).
- Equal-volume and spectral measurements or any trained audio reference comparison.
- Native `.kipr`/`.kperform` files. None are provided.

## Source quality policy

Categories: `original_artifact` (specific previous spec available), `reconstructed_from_chat` (prior plans and summary available, exact file not), `engineering_target` (proposed tone approximation), `historically_documented` (only when cited). Never silently elevate a reconstructed setting into a documented recorded fact.
